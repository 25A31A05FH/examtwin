##  Project Overview

ExamSeat Pro is a web-based Smart Examination Seating Arrangement System developed to simplify and automate the process of assigning students to examination rooms.

Traditional examination seating arrangements are often managed manually, which requires considerable time and effort and can lead to errors, duplicate seat allocation, and inefficient room utilization.

ExamSeat Pro provides a digital solution that allows examination administrators to manage examination details, upload student information, configure examination rooms, and generate seating arrangements efficiently.

The system aims to improve accuracy, save time, reduce manual work, and provide an organized examination management experience.

##  System Architecture

ExamSeat Pro follows a frontend-backend architecture.

1. **Frontend:** Provides the user interface for registration, login, examination management, student uploads, and seating arrangement generation.
2. **Backend:** Handles server-side operations and API requests.
3. **Database:** SQLite is used for storing supported application records.
4. **Deployment:** GitHub Pages hosts the frontend, while Render hosts the backend service.

##  Installation and Setup

Follow these steps to run the project locally.

### Prerequisites

Install the following tools:

- Node.js
- Bun or npm
- Git
- Visual Studio Code

### Step 1: Clone the Repository

```bash
git clone https://github.com/Jahnavi-chaganti/examtwinn.git
```

### Step 2: Navigate to the Project Folder

```bash
cd examtwinn
```

### Step 3: Install Dependencies

Using Bun:

```bash
bun install
```

Alternatively, using npm:

```bash
npm install
```

### Step 4: Configure Environment Variables

Create a `.env` file in the project root and configure the environment variables required by your local setup.

Refer to `.env.example` for the available configuration options.

Do not upload private API keys or passwords to GitHub.

### Step 5: Run the Development Server

```bash
bun run dev
```

### Step 6: Create a Production Build

```bash
bun run build
```

### Step 7: Start the Backend Server

```bash
bun run start
```
